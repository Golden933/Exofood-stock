# Exo'Food Stock

MVP de gestion de stock Exo'Food.

## Déploiement Railway
1. Déployer ce dépôt depuis GitHub.
2. Railway détecte le Dockerfile.
3. Dans Settings > Networking, cliquer Generate Domain.
4. Ouvrir l'URL publique.

## Démo
Aucune authentification n'est requise dans ce MVP de démonstration.
Les données sont initialisées automatiquement dans SQLite au premier lancement.
